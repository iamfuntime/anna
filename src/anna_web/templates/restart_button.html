{# Restart-button partial (subtask 10). Two states keyed off the `state` context variable: * `idle` — the default. Renders the confirm-then-POST form. `/restart` POST returns this partial in the `restarting` state on success or the same idle state plus an error toast on failure. * `restarting` — optimistic UI rendered immediately after the restart dispatches. Embeds a small inline poller that pings `/healthz` (subtask 11) every 2s and swaps the partial back to idle after three consecutive `anna_running: true` responses. The inline-JS choice over pure-HTMX is documented in the route module's docstring — `/healthz` returns JSON, not HTML, and counting "good response streaks" client-side is cleaner than coercing HTMX swap semantics to do it. Both states render inside the same outermost wrapper so HTMX's `hx-target="this"` / `hx-swap="outerHTML"` on the form replaces the entire partial atomically.
