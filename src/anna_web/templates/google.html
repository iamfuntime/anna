Google accounts

Connect Gmail and Calendar (read-only) through Google's own consent screen. This page runs on this machine only. What this does not do: it does not register an app for you (you create one Desktop OAuth client in your own Google Cloud project, once, and every mailbox shares it) and it does not make your app "verified" by Google — an unverified External app shows a warning at consent and, while in Testing, refresh tokens expire after 7 days. Workspace accounts work as user OAuth if your admin allows the app.
